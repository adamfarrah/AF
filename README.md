## Featured Project

### Designing & Securing an Enterprise Network
**Graduation Project** · Grade: **16/20**

Complete methodology for designing, securing and supervising a LAN — from audit to penetration testing.

**Stack & Tools:** GNS3 · Cisco IOS · pfSense · Zabbix · VLAN/802.1Q · VLSM · ACL · NAT · 802.1X/RADIUS · IPSec & OpenVPN · Rapid-PVST+ · DHCP Snooping · DAI · SNMP/Syslog

**Validation (simulated attacks):**
- Nmap port scan → filtered
- VLAN hopping → blocked
- ARP spoofing → rejected by DAI
- MAC flooding → err-disable
